# homebrew-grimoire-cli

Homebrew tap for [grimoire-cli](https://github.com/thomaslazar/grimoire-cli) — a command-line interface for Grimoire, the self-hosted TTRPG library manager.

## Install

```bash
brew tap thomaslazar/grimoire-cli
brew install grimoire-cli
```

## Update

```bash
brew upgrade grimoire-cli
```

## Note

`Formula/grimoire-cli.rb` is written by grimoire-cli's release workflow — do not edit it here. It is generated from `.github/homebrew/grimoire-cli.rb.template` in that repo and pushed on each release.
